# BelegManager

BelegManager ist ein digitaler Beleg-Scanner für Geschäftsausgaben. Belege werden per Foto erfasst, automatisch ausgelesen (Betrag, MwSt., Datum, Händler) und DSGVO-/GoBD-konform für Buchhaltung und Steuerberater aufbereitet — inklusive DATEV-CSV-Export, Fahrtkosten-Erfassung und mehrsprachiger Oberfläche (DE, EN, TR, AR, RU).

Gebaut mit **React**, **Vite**, **TypeScript**, **Tailwind CSS** und **Supabase** (Auth, Datenbank, Storage, Edge Functions) über Lovable Cloud.
